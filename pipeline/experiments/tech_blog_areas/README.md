# Tech Blog Areas Experiment

F-02 조직 파악 기능을 위한 기술블로그 기반 영역 추출 실험입니다.

## 목표

최근 12개월 기술블로그 게시글을 기반으로 회사가 반복해서 다루는
엔지니어링 영역 3~5개를 사전 정의 taxonomy 없이 생성할 수 있는지 검증합니다.

## 실험 흐름

1. collect
   - 최근 12개월 기술블로그 게시글 메타데이터 수집

2. extract
   - 게시글 본문 추출

3. embed
   - 게시글을 임베딩 벡터로 변환

4. cluster
   - 의미가 비슷한 게시글을 그룹화

5. inspect
   - 각 클러스터가 실제로 하나의 엔지니어링 영역으로 볼 수 있는지 확인

## 원칙

- 모든 게시글에 LLM 정밀 분석을 수행하지 않는다.
- 영역은 사전 정의 목록에 맞추지 않는다.
- 빈도 계산은 Python 코드로 수행한다.
- 뉴스와 채용공고는 기술블로그에서 생성한 영역에만 연결한다.
- 기술블로그 본문 전체와 중간 산출물은 Git에 커밋하지 않는다.
