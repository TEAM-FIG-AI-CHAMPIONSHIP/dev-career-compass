# 회사 아이콘

이 폴더에 파일을 넣고 `data/**/index.json` 의 해당 회사에 `logoSrc` 를 적으면
화면에 나옵니다.

```
apps/web/public/companies/oliveyoung.svg
```

```json
{ "slug": "oliveyoung", "name": "올리브영", "mark": "올",
  "logoSrc": "/companies/oliveyoung.svg" }
```

## 규칙

- **파일명은 회사 slug 와 같게** 둡니다. `index.json` 을 기계적으로 채울 수
  있고, 어느 파일이 어느 회사인지 찾을 때 헤매지 않습니다.
- **SVG 를 권합니다.** 목록에서 32px, 선택된 회사 패널에서 36px 로 그려집니다.
  PNG 라면 72px 이상(3배)으로 주세요.
- **정사각**으로 맞추고 여백은 파일 안에 포함합니다. 화면은 `object-contain`
  으로 비율만 지키고 여백을 만들어 주지 않습니다.
- **배경은 넣어도 되고 빼도 됩니다.** 회사 고유색 배경이 있으면 그대로 두세요 —
  담는 상자가 흰 바탕에 실선 테두리라 어느 쪽이든 섭니다.
- `logoSrc` 를 적지 않은 회사는 **이름 첫 글자**(`mark`)로 나옵니다. 아이콘이
  없는 회사는 계속 생기므로 이 대체는 지우지 않습니다.

## 왜 `next/image` 가 아닌가

Next 의 이미지 최적화는 SVG 를 기본으로 막습니다(원격 SVG 안의 스크립트
때문입니다). 회사 아이콘은 저장소에 직접 넣는 작은 파일이라 최적화가 필요
없어서, 설정을 전역으로 여는 대신 `CompanyMark` 안에서 `img` 를 씁니다.
