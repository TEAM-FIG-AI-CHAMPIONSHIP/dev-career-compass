## 작업 내용

- 1차 게이트 통과는 **34곳**이다. 기준(직무당 최근 12개월 기술글 8개)은 낮추지 않는다.
- 수기 확인 여력이 없어, unknown 38곳 중 우선순위 높은 **16곳**을 노출 후보로만 더한다. 이 16곳은 게이트를 통과한 것이 아니다.
- 노출 후보 풀은 **50곳 = 통과 34 + 후보 16**이다. 60~80을 맞추려고 fail을 넣지 않는다. Area / embedding / clustering / LLM은 범위 밖이다.
- 문서와 `candidate_companies.json`만 갱신한다. 수집 스크립트와 `verdict=pass` 목록은 바꾸지 않는다.
