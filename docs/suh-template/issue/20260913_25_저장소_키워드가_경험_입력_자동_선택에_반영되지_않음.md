# [fix] 저장소 키워드가 경험 입력 자동 선택에 반영되지 않음

라벨: 없음
담당자: 미지정

---

## 작업 내용

- `apps/web/src/components/experience/ExperienceForm.tsx`의 초기 체크값 계산 로직 `itemIds: stored?.itemIds ?? suggestedItemIds`에 회귀가 있다. `stored`(기존에 저장된 경험 입력)가 존재하면 그 값이 빈 배열이어도 `??` 연산자가 통과시키지 않아 `suggestedItemIds`(저장소 키워드 기반 제안)가 통째로 무시된다. 즉 경험 입력 화면에 한 번이라도 들어간 적 있는 브라우저에서는 그 이후로 GitHub 키워드 제안이 절대 반영되지 않는다.
- 제안으로 자동 체크된 항목과 사용자가 직접 고른 항목이 화면에서 완전히 동일하게 보인다. 정상 동작해도 어떤 항목이 GitHub 키워드로 자동 선택된 것인지 구분할 방법이 없다.

## 완료 기준

- [ ] 저장소를 분석해 키워드를 얻은 뒤 경험 입력 화면에 들어가면, 이전에 그 화면을 방문한 적이 있어도(기존 저장값이 빈 배열인 경우 포함) 새로 계산된 제안 항목이 반영된다.
- [ ] 자동 선택된 항목과 사용자가 직접 고른 항목을 화면에서 구분할 수 있다.
- [ ] 사용자가 자동 선택된 항목을 자유롭게 해제·수정할 수 있는 기존 동작은 그대로 유지된다.

## 참고 사항

- 관련 파일: `apps/web/src/components/experience/ExperienceForm.tsx`, `apps/web/src/lib/keyword-experience.ts`
- 저장소 키워드 추출 자체는 #17에서 구현됐고, 키워드→경험 항목 매핑과 초기 체크 로직은 #19("S5 경험 입력 단계 구현")에서 추가됐다.
- `stored`와 `suggestedItemIds`를 어떻게 합칠지(예: 화면에 처음 들어왔을 때만 제안을 적용할지, 이미 고른 항목 위에 새 제안을 추가로 얹을지)는 구현 전에 정해야 한다.
