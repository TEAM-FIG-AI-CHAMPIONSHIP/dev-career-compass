# fixtures 는 화면용 임시 분석 데이터입니다

회사·직무 범위와 분석 본문의 확정 상태를 구분합니다.

## 회사·직무 인덱스

`index.json`은 `/companies`가 읽는 회사·직무 목록입니다. PR #96과 #100의
Area evidence 게이트 결과를 합쳐 다음 범위를 담습니다.

- 회사 33곳
- 회사×직무 112개
- 서버·백엔드 32곳, 웹 프론트엔드 29곳, 모바일 18곳, 데이터·AI 33곳
- 회사의 `areas[].evidence[]`를 `article_id`로 중복 제거한 뒤, 직무별 근거 글이
  4건 이상인 조합만 포함
- `unassigned`와 구름 제외

각 회사와 직무의 `evidenceCount`는 위 집계에서 나온 고유 근거 글 수입니다.
한 글에 여러 직무가 붙을 수 있으므로 직무별 건수의 합은 회사 전체 근거 글
수보다 클 수 있습니다.

## 분석 fixture

회사별 하위 디렉터리의 JSON은 화면 흐름을 확인하기 위한 임시 분석입니다.
`oliveyoung/backend.json`만 화면을 채운 예시이고, 나머지 파일은 `domains`,
`suggestions`, `evidence`가 빈 배열입니다. 실제 Area 분석 결과로 읽으면 안 됩니다.

확정된 112개 조합 모두의 분석 본문이 아직 없으므로 `index.json`의 회사 상태는
`collecting`입니다. `/companies`에서는 확정된 직무와 근거 건수를 보여주되 결과
페이지 링크는 열지 않습니다. 없는 분석을 만들거나 게시 상태로 표시하지 않기
위한 조치입니다.

`/match`의 직무별 회사 수는 현재 하위 디렉터리에 존재하는 fixture 파일을
기준으로 계산하므로 `/companies`의 확정 범위와 별개입니다. 실제 분석 결과가
`data/published`에 들어오면 웹은 그 디렉터리를 우선해서 읽습니다.

## 데이터 모양

`apps/web/src/types/data.ts`가 웹에서 사용하는 내부 타입을 정의합니다. 파이프라인
계약 자체는 아니며, 게시 산출물 형식이 확정되면 그 형식에 맞춰 갱신합니다.
