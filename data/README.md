# Data

웹 애플리케이션과 데이터 파이프라인 사이의 파일 기반 경계입니다.

## Directories

- fixtures: 파이프라인 완성 전 프론트 개발과 테스트에 사용하는 가짜 데이터
- published: 검증을 통과해 웹에 제공할 최종 구조화 데이터

수집 원문과 분석 중간 결과는 raw, work, intermediate 디렉터리에 둘 수 있지만 Git에는 커밋하지 않습니다.

다음 데이터는 이 저장소에 저장하지 않습니다.

- 기술 블로그와 채용 공고의 본문 전체
- 사용자가 입력한 경험 값
- GitHub README 원문
- API 키와 개인정보
