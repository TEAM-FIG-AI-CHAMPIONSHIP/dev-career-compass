# 1차 게이트 검수 메모

관련: D2·카카오·당근·요기요 보강 (이전 #40 #30)

통과 회사는 **34곳**이다. 기준(직무당 기술글 8개)은 낮추지 않았다.

수기 확인 여력이 없어, unknown 중 우선순위 높은 **16곳**을 후보로만 더한다.
노출 후보 풀은 **50곳 = 통과 34 + 후보 16**이다.
후보 16곳은 게이트를 통과한 것이 아니다. `verdict`는 그대로 `unknown`이다.

이번 보강 결과:

| 회사 | 판정 | 결과 |
| --- | --- | --- |
| 네이버 | pass | D2 목록 API 69건. 데이터·AI 10 |
| 카카오 | pass | sitemap+본문. 백엔드 17, 데이터·AI 15 |
| 당근마켓 / 당근 | pass | Medium stream 25건. 프론트 9 |
| LG AI연구원 | pass | `?seq=` 글 복구 후 본문 분류. 4직무 |
| 위대한상상 / 요기요 | fail | 12개월 닫힘. 기술글 8, 직무당 8 미만 |
| 딜라이트룸 | fail | 12개월 닫힘. 기술글 12, 직무당 8 미만 |
| SSG.COM | fail | 12개월 닫힘. 기술글 5 |
| 미리디 | unknown → 후보 1 | 프론트 7. 창 미닫힘 |
| 무신사 / 29CM | unknown → 후보 2 | RSS/sitemap 중복 URL 제거 후 데이터·AI 5 |

대기업이라서 pass를 주지 않았다. 요기요·딜라이트룸·SSG는 글이 모였고, 8개 게이트에서 떨어졌다. 후보 16곳에도 넣지 않았다.
